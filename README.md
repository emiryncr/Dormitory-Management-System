
# Dormitory-Management-System

In this project, the instructor gave us tasks and it was created according to the given tasks.


## Aim

First steps of full-stack web development. Project includes HTML-CSS-JS, PHP, MySql.

  
## Roadmap

- Week 1 : Create sign-up and log-in pages

- Week 2 : Create Student, Manager and admin pages

- Week 3 : Create sub links for admin.php

- Week 4 : Create sub links for manager.php

- Other weeks : Backend and all other final tasks given
  
## How to run

Install XAMPP Control Panel, go [XAMPP Website](https://www.apachefriends.org/download.html)


Find folder where your projects run

```bash
  "C:\xampp\htdocs"
```

Clone project

```bash
  git clone https://github.com/emiryncr/Dormitory-Management-System
```

Run server

```bash
  Start Apache server, then open your browser and search "localhost/folder-name"
```
