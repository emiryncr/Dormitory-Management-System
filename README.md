## How to run

Install XAMPP Control Panel

```bash
  go [XAMPP Website](https://www.apachefriends.org/download.html)
```

Find folder where your projects run

```bash
  "C:\xampp\htdocs"
```

Clone project

```bash
  git clone https://github.com/emiryncr/Dormitory-Management-System
```

Run server

```bash
  Start Apache server, then open your browser and search "localhost/folder-name"
```
